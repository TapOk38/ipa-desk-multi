# IPA Install — установка с Windows

Устанавливает готовый IPA-файл на iPhone с компьютера через USB. На iPhone заранее ничего устанавливать не нужно.

**[Скачать IPA-Install.exe](https://github.com/TapOk38/ipa-desk-multi/releases/download/install-v1.0.0-beta.1/IPA-Install.exe)**

## Что нужно

Windows 10/11 x64, драйвер Apple, USB-кабель с передачей данных и IPA-файл. Драйвер можно установить вместе с **Apple Devices** из Microsoft Store. Если IPA ещё нет — скачайте его через [IPA Desk Multi](../docs/DOWNLOAD.md).

## Как установить

1. Запустите EXE и подключите разблокированный iPhone к ПК. Подтвердите доверие на телефоне, если появится запрос.
2. Нажмите **«Обновить»** — должна появиться модель iPhone. Через **«Выбрать…»** укажите IPA.
3. Нажмите **«Установить»** и дождитесь **«Приложение установлено»**, не отключая кабель.

Откройте приложение на iPhone. Если он запросит Apple ID и пароль, используйте учётку, с которой скачан IPA.

Для следующего iPhone переподключите кабель и нажмите **«Обновить»**. Подключайте по одному телефону.

## Дополнительно

Кнопка **«Учётные данные iCloud»** позволяет сохранить Apple ID и пароль для показа после установки. Ввод на iPhone выполняется вручную. Сохраняется одна общая учётка — при смене IPA она автоматически не меняется. Для установки сохранять учётку необязательно.

## Если не работает

- **iPhone не виден:** проверьте кабель, доверие и определяется ли телефон в Apple Devices.
- **Ошибка установки:** посмотрите журнал. IPA должен быть совместим с iOS и иметь действующую подпись; программа не переподписывает файл и не снимает привязку к Apple ID.
