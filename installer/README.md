# IPA Install

**Устанавливает готовый IPA-файл на iPhone с компьютера Windows через USB-кабель.** На iPhone заранее ничего устанавливать не нужно.

**[Скачать IPA-Install.exe](https://github.com/TapOk38/ipa-desk-multi/releases/download/install-v1.0.0-beta.1/IPA-Install.exe)**

## Что понадобится

- 64-разрядная Windows с Windows PowerShell 5.1, например Windows 10 или 11.
- iPhone и USB-кабель с передачей данных.
- Установленные драйверы Apple. Если компьютер не видит iPhone, установите **Apple Devices** из Microsoft Store и проверьте, определяется ли телефон в этой программе.
- Файл приложения с расширением **.ipa**. Если его нет, скачайте его с помощью [IPA Desk Multi](../README.md).

## Как установить приложение

1. Скачайте **IPA-Install.exe** по ссылке выше. Откройте папку **«Загрузки»** Windows и запустите файл двойным щелчком.
2. Подключите iPhone к компьютеру кабелем и разблокируйте его. Если появится вопрос **«Доверять этому компьютеру?»**, нажмите **«Доверять»** и введите код-пароль iPhone.
3. В IPA Install нажмите **«Обновить»**. В строке **«iPhone»** должны появиться модель телефона и версия iOS.
4. Нажмите **«Выбрать…»** в строке **«IPA-файл»** и укажите нужный файл.
5. Нажмите **«Установить»**. Не отсоединяйте кабель, пока не появится сообщение **«Приложение установлено»**.
6. Откройте установленное приложение на iPhone. Если он запросит Apple ID и пароль, введите данные учётки, с которой скачан IPA. Она может отличаться от основной учётки телефона.

Для другого iPhone переподключите кабель и нажмите **«Обновить»**. Подключайте по одному телефону.

## Кнопка «Учётные данные iCloud»

Можно заранее сохранить Apple ID и пароль, чтобы после успешной установки программа показала их крупным текстом. Это необязательно: установка работает и без сохранения учётки.

Сохраняется одна общая учётка. При выборе другого IPA она не меняется автоматически. Данные вводятся на iPhone вручную.

## Если не получилось

- **iPhone не появляется:** разблокируйте его, проверьте кабель, драйвер Apple и нажмите **«Обновить»**.
- **Нужна более новая iOS:** программа укажет требуемую версию в журнале.
- **Ошибка установки:** прочитайте сообщение в нижней части окна. Установить получится не любой IPA — файл должен подходить вашему iPhone; программа не меняет подпись и не снимает привязку к Apple ID.
- **Нужна помощь:** [сообщите об ошибке](https://github.com/TapOk38/ipa-desk-multi/issues), указав IPA Install и текст ошибки без личных данных.

Все USB-утилиты входят в EXE. Они не заменяют драйвер Apple. Для установки нужна свободная память на iPhone и место на компьютере для временной копии IPA.
