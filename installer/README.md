# IPA Install

Устанавливает готовые IPA-файлы на iPhone с Windows через USB. На iPhone заранее ничего устанавливать не нужно.

**[Скачать IPA-Install.exe](https://github.com/TapOk38/ipa-desk-multi/releases/download/install-v1.0.0-beta.1/IPA-Install.exe)**

Нужны **Windows 10/11 x64**, драйвер Apple, USB-кабель с передачей данных и файл IPA. Драйвер можно установить вместе с **Apple Devices** из Microsoft Store. Если IPA ещё нет — используйте [IPA Desk Multi](../README.md).

## Установка

1. Запустите EXE, подключите разблокированный iPhone и подтвердите доверие на телефоне, если появится запрос.
2. Нажмите **«Обновить»**, затем **«Выбрать…»** и укажите IPA.
3. Нажмите **«Установить»**. Не отключайте кабель до сообщения **«Приложение установлено»**.

Если при запуске приложения iPhone запросит Apple ID, используйте учётку, с которой скачан IPA. Программа не меняет подпись и не снимает привязку к учётке.

Для следующего iPhone переподключите кабель и нажмите **«Обновить»**. Подключайте по одному телефону.

## Учётные данные iCloud

Необязательная кнопка для сохранения Apple ID и пароля: после установки программа покажет их на экране для ручного ввода на iPhone. Сохраняется **одна общая учётка** — при выборе другого IPA она автоматически не меняется.

## Если не работает

- **iPhone не виден:** проверьте кабель, доверие и определяется ли телефон в Apple Devices.
- **Ошибка установки:** посмотрите журнал — IPA должен быть совместим с версией iOS и иметь действующую подпись.
