# IPA Install

Устанавливает готовые IPA-файлы на iPhone с Windows через USB. Предварительная установка программ на iPhone не требуется.

**[Скачать EXE](https://github.com/TapOk38/ipa-desk-multi/releases/download/install-v1.0.0-beta.1/IPA-Install.exe)** · Версия 1.0.0-beta.1

## Требования

Windows 10/11 x64, драйвер Apple, USB-кабель с передачей данных и IPA-файл. Драйвер устанавливается вместе с [Apple Devices из Microsoft Store](https://apps.microsoft.com/detail/9np83lwlpz9k).

Для скачивания IPA из App Store используйте [IPA Desk Multi](../docs/DOWNLOAD.md).

## Использование

1. Запустите EXE и подключите разблокированный iPhone. Подтвердите доверие на телефоне, если появится запрос.
2. Нажмите **«Обновить»** и убедитесь, что отображается модель iPhone. Через **«Выбрать…»** укажите IPA.
3. Нажмите **«Установить»**. Не отключайте кабель до сообщения **«Приложение установлено»**.

Откройте приложение на iPhone. Если потребуется Apple ID и пароль, введите данные учётной записи, с которой скачан IPA.

Для другого iPhone переподключите кабель и нажмите **«Обновить»**. Подключайте по одному устройству.

<details>
<summary>Сохранение учётных данных — необязательно</summary>

Кнопка **«Учётные данные iCloud»** сохраняет Apple ID и пароль для показа после установки. Данные вводятся на iPhone вручную. Сохраняется одна общая учётная запись; при смене IPA она автоматически не меняется.

</details>

## Решение проблем

- **iPhone не определяется:** проверьте кабель, доверие и подключение в Apple Devices.
- **Ошибка установки:** проверьте журнал. IPA должен быть совместим с iOS и иметь действующую подпись. Программа не переподписывает файл и не снимает привязку к Apple ID.
