# IPA Install

Устанавливает готовые IPA-файлы на iPhone с Windows через USB.

**[Скачать IPA-Install.exe](https://github.com/TapOk38/ipa-desk-multi/releases/download/install-v1.0.0-beta.1/IPA-Install.exe)**

Нужны Windows 10/11 x64 и драйвер Apple. Запустите EXE, подключите iPhone, выберите IPA и нажмите **«Установить»**. На iPhone заранее ничего устанавливать не нужно.

[Инструкция](https://github.com/TapOk38/ipa-desk-multi/tree/main/installer#readme) · [Скачать IPA из App Store](https://github.com/TapOk38/ipa-desk-multi#readme)
