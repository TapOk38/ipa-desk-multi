# IPA Install для Windows

Устанавливает готовый IPA-файл на iPhone через USB. На iPhone заранее ничего устанавливать не нужно.

**[Скачать IPA-Install.exe](https://github.com/TapOk38/ipa-desk-multi/releases/download/install-v1.0.0-beta.1/IPA-Install.exe)**

1. Откройте скачанный EXE.
2. Подключите разблокированный iPhone к компьютеру, подтвердите доверие и нажмите **«Обновить»**.
3. Нажмите **«Выбрать…»**, укажите IPA и нажмите **«Установить»**.
4. Дождитесь сообщения **«Приложение установлено»** и откройте приложение на iPhone.

Если iPhone запросит Apple ID, используйте учётку, с которой скачан IPA. Кнопка **«Учётные данные iCloud»** позволяет сохранить эти данные для показа после установки.

Все USB-утилиты внутри EXE. Требуются 64-разрядная Windows, Windows PowerShell 5.1 и драйвер Apple.
