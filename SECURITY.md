# Сообщения о безопасности

Для обычной ошибки откройте Issue: укажите версию программы, шаги и текст ошибки.
Скройте личные данные в журнале и скриншотах. Не прикладывайте пароли, коды 2FA,
`accounts.json`, файлы сессий или IPA с данными учётки.

Об уязвимости сообщайте через **Security → Report a vulnerability**, если этот раздел доступен.
Иначе откройте Issue с просьбой о приватном контакте, без секретов и подробностей эксплуатации.
