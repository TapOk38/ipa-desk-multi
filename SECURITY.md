# Сообщения о безопасности

Не публикуйте Apple ID, пароли, коды 2FA, IPA с данными аккаунта, записи доверия,
cookies или приватные ключи в Issues. Для проблемы без секретов достаточно версии,
шагов воспроизведения и обезличенного текста ошибки.

Для уязвимости используйте **Security → Report a vulnerability**, если владелец включил
Private vulnerability reporting. Если этот канал ещё недоступен, откройте Issue с просьбой
о приватном контакте, без деталей эксплуатации и секретов. Публичный журнал не является
каналом передачи учётных данных. Пока поддерживается только последняя бета-версия.
