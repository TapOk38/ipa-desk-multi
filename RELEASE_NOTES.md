# IPA Desk Multi 0.3.0-beta.1

Скачайте `ipa-desk-multi-0.3.0-beta.1-windows.zip`, распакуйте и откройте Start.cmd.
Windows x64, PowerShell 5.1, доступ к GitHub при первой подготовке и к Apple для скачивания.
Для каждой выбранной учётки создаётся отдельный IPA. На iPhone заранее устанавливать
скачиваемое приложение не требуется. Возможен ручной ввод кода 2FA.

Публичный ZIP содержит нашу оболочку; ipatool-cpp 1.0.9 получается непосредственно
из upstream и проверяется по SHA-256. Сохранённые учётки локальных v1–v3 доступны автоматически
под тем же пользователем Windows. Не запускайте старую и новую версии одновременно.

Регрессионные тесты используют имитацию ответов Apple. Владелец проекта подтвердил
работу подготовленного выпуска 12.10.2026. Выпуск опубликован как Pre-release.
