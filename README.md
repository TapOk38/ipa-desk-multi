# IPA Desk — приложения для Windows

Две программы: одна скачивает приложение из App Store в файл IPA, другая устанавливает этот файл на iPhone через USB.

## Скачать

| Что нужно сделать | Программа и ссылка |
| --- | --- |
| Скачать приложение из App Store на компьютер | **[Скачать IPA Desk Multi.exe](https://github.com/TapOk38/ipa-desk-multi/releases/download/v0.3.1-beta.1/IPA-Desk-Multi-0.3.1-beta.1.exe)** |
| Установить готовый IPA на iPhone с компьютера | **[Скачать IPA-Install.exe](https://github.com/TapOk38/ipa-desk-multi/releases/download/install-v1.0.0-beta.1/IPA-Install.exe)** |

Нужна 64-разрядная Windows с Windows PowerShell 5.1 — он уже входит в Windows 10 и 11. Для запуска достаточно скачать EXE и открыть его двойным щелчком. Распаковывать архив не нужно.

**IPA** — файл приложения для iPhone. Если IPA у вас уже есть, переходите к [установке на iPhone](installer/README.md).

## Как скачать IPA через IPA Desk Multi

1. Нажмите **«Скачать IPA Desk Multi.exe»** выше. Найдите файл в папке **«Загрузки»** Windows и откройте его.
2. Нажмите **«Добавить»**. Введите Apple ID — адрес электронной почты учётной записи Apple — и её пароль. В поле **«Описание»** можно написать имя или другую удобную пометку. Нажмите **«Сохранить»**.
3. Откройте страницу нужного приложения в App Store. На iPhone выберите **«Поделиться приложением» → «Скопировать ссылку»**, затем передайте ссылку на компьютер. Если страница открыта в браузере компьютера, скопируйте её адрес.
4. Вставьте ссылку в поле **«Ссылка или ID»**. Если вы уже знаете числовой ID приложения, можно вставить его вместо ссылки.
5. Поставьте галочки рядом с нужными учётными записями и нажмите **«Скачать IPA»**. Можно выбрать одну учётку или несколько — программа обработает их по очереди.
6. Если появится окно **«Код подтверждения»**, введите шестизначный код для указанной учётки и нажмите **«Продолжить»**.
7. Дождитесь результата **«IPA сохранён»** напротив учётки. Нажмите **«Открыть папку»**, чтобы найти скачанные файлы.

Файлы находятся в **«Загрузки → IPA Desk Multi»**, внутри папок приложения и учётных записей. Для каждой выбранной учётки сохраняется отдельный IPA. В его имени указаны приложение, версия, Apple ID и ваша пометка.

Подключать iPhone к компьютеру или заранее устанавливать на него скачиваемое приложение не нужно. При первом скачивании программа автоматически подготовит необходимый компонент — дождитесь завершения.

## Что делать со скачанным файлом

- **Установить через компьютер:** воспользуйтесь [IPA Install](installer/README.md).
- **Установить через Android:** перенесите IPA на Android и следуйте [инструкции IPA USB](https://github.com/TapOk38/ipa-usb-android#readme).

Для запуска приложения на iPhone может потребоваться Apple ID, с которым скачан IPA.

## Учётные записи и ошибки

Учётки сохраняются между запусками. Их можно изменять и удалять. Старые учётки IPA Desk Multi подхватываются под тем же пользователем Windows; на другом компьютере пароль потребуется ввести заново.

Приложение должно быть доступно выбранной учётке. Для бесплатного приложения программа при необходимости получает лицензию. Платные покупки не выполняются.

При ошибке прочитайте сообщение внизу окна. Если нужна помощь, [сообщите об ошибке](https://github.com/TapOk38/ipa-desk-multi/issues), скрыв адреса учёток и личные данные. Не повторяйте неудачный вход много раз подряд. Не рекомендуем массовое скачивание со сменой множества Apple ID на одном ПК: подтверждённого безопасного количества учёток нет.
