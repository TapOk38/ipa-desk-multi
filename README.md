# IPA Desk Multi

Windows-интерфейс для скачивания одного приложения App Store для нескольких выбранных
Apple ID по очереди. **0.3.0-beta.1 — публичная бета на основе локальной версии v3.**
Windows GUI for sequential, per-account IPA downloads with ipatool-cpp.

![Окно программы без учётных данных](docs/interface.png)

Для каждой учётки сохраняется отдельный IPA. Заранее устанавливать приложение на iPhone
и подключать iPhone к ПК не требуется. Если бесплатное приложение ещё не получено,
компонент запрашивает бесплатную лицензию. Приложение должно быть доступно выбранной учётке;
наличие ссылки/ID не гарантирует загрузку удалённого приложения.

## Запуск

1. Скачайте `ipa-desk-multi-0.3.0-beta.1-windows.zip` из Releases и распакуйте целиком.
2. Запустите `Start.cmd`. Нужны Windows x64 и Windows PowerShell 5.1.
3. Добавьте Apple ID, пароль и необязательное описание владельца/отдела.
4. Вставьте ссылку App Store или числовой ID, отметьте учётки и нажмите «Скачать IPA».
5. При первом скачивании программа получает ipatool-cpp 1.0.9 из релиза его автора на GitHub.
   Архив и EXE проверяются по зафиксированным SHA-256. Дальше используется локальная копия.
6. Если Apple запросит 2FA, введите код для учётки, указанной в окне.

Если GitHub недоступен, скачайте официальный архив по ссылке в [зависимостях](THIRD_PARTY.md)
на другом соединении, затем выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Tools.ps1 -ArchivePath C:\Downloads\windows_amd64_ipatool-cpp.zip
```

Никакие скрипты из интернета не исполняются. Компонент скачивается с GitHub, а авторизация
и скачивание IPA выполняются компонентом через серверы Apple. Apple ID не передаётся GitHub.

## Файлы и учётки

IPA сохраняются в `Downloads/ID приложения/учётка/` рядом с программой.
Имя: `Название_Версия_iOS_МинимальнаяВерсия+_AppleID_Описание.ipa`.
Метаданные берутся из IPA; описание вводится пользователем. Русские пути и описания поддержаны
через отдельную передачу рабочей папки процессу. Существующие файлы не перезаписываются.

Учётки можно добавлять, изменять и удалять. Пароли защищены Windows DPAPI и находятся в
`%LOCALAPPDATA%/IPA-Desk-Multi/accounts.json`; для переноса на другой ПК их нужно ввести заново.
Существующие учётки локальных v1–v3 доступны под тем же пользователем Windows. Закройте старую
версию перед новой. Новые платные приложения не приобретаются.

## Ограничения и данные

- При ошибке одной учётки очередь продолжает работу; «Отмена» останавливает очередь.
- Вход выполняется заново для каждой операции в отдельном профиле; повторный запрос 2FA возможен.
- Пароль, начинающийся с дефиса, не поддержан компонентом; программа сообщит об этом до входа.
- Нет гарантии отсутствия ограничений Apple и подтверждённого «безопасного количества» учёток.
  Не рекомендуем массовые смены Apple ID и многократные повторы неудачного входа.
- Пароль передаётся дочернему CLI через аргументы. Локальный процесс с достаточными правами
  может их прочитать. DPAPI защищает сохранённые данные, но не делает заражённый ПК безопасным.
- Нет телеметрии. Подробности хранения и сетевых обращений: [PRIVACY.md](PRIVACY.md).

## Разработка и проверка

PowerShell 5.1, WinForms и встроенный .NET Framework; сборка EXE для оболочки не нужна.
Тесты `tests/Test-Engine.ps1` используют вымышленные учётки и имитируют ответы Apple.
`tests/Test-Tools.ps1` проверяет установку компонента без входа в Apple.
[Сборка ZIP и проверка релиза](docs/BUILDING.md). Автоматические тесты не подтверждают
работоспособность текущего сервера Apple. Владелец проекта подтвердил работу
подготовленного выпуска 12.10.2026; это не гарантирует доступность серверов Apple в будущем.
