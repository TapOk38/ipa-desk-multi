# IPA Desk

Набор программ для скачивания приложений из App Store и установки IPA-файлов на iPhone с Windows или Android.

## Выбор программы

| Задача | Программа и инструкция | Платформа |
| --- | --- | --- |
| Скачать IPA из App Store для одной или нескольких учётных записей | [**IPA Desk Multi**](docs/DOWNLOAD.md) | Windows 10/11 x64 |
| Установить готовый IPA на iPhone с компьютера через USB | [**IPA Install**](installer/README.md) | Windows 10/11 x64 |
| Установить готовый IPA на iPhone с Android через USB | [**IPA USB**](android/README.md) | Android 8.0+, OTG |

**IPA** — файл приложения для iPhone. Если файла ещё нет, начните с IPA Desk Multi. Если он уже есть, выберите один из установщиков. Ссылки на скачивание доступны на странице каждой программы.

Предварительная установка программ на iPhone не требуется. При запуске приложения из App Store может понадобиться Apple ID, с которым скачан IPA.
