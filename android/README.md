# IPA USB

<details>
<summary>English</summary>

Installs IPA files on an iPhone from Android over USB.

**[Download APK](https://github.com/TapOk38/ipa-desk-multi/releases/download/suite-v1.0.0-beta.3/ipa-usb-0.7.0-beta.3.apk)** · 0.7.0-beta.3

## Requirements

Android 8.0+ with OTG support, a USB data cable and an IPA file saved on Android. An OTG adapter or USB hub may be required.

## Usage

1. Install the APK and select the interface language. Save the IPA on Android.
2. Enable OTG if your device has this setting. Connect the phones with the cable and unlock the iPhone.
3. Tap **Connect**. Allow USB access on Android and confirm trust on the iPhone if prompted.
4. Tap **Select IPA**, select the file, then tap **Install**. Keep the cable connected until **App installed** appears.

If the app requests an Apple ID when launched, use the account that downloaded the IPA.

## Troubleshooting

- **iPhone not detected:** check OTG and the cable. If USB-C ↔ USB-C fails, connect an OTG adapter or hub to Android, then connect the iPhone to it. [Connection help](docs/TESTING.md).
- **Installation error:** the IPA must be compatible with iOS and have a valid signature. The tool does not re-sign files or remove their Apple ID association.

To report an error, tap **Save log** and remove personal information from the log.

Устанавливает IPA на iPhone с Android через USB.

**[Скачать APK](https://github.com/TapOk38/ipa-desk-multi/releases/download/suite-v1.0.0-beta.3/ipa-usb-0.7.0-beta.3.apk)** · 0.7.0-beta.3

## Требования

Android 8.0+ с поддержкой OTG, USB-кабель с передачей данных и IPA-файл на Android. При необходимости используется OTG-переходник или USB-хаб.

## Использование

1. Установите APK. Для русского интерфейса переключите **EN → RU**. Сохраните нужный IPA на Android.
2. Включите OTG, если такой переключатель есть в настройках. Соедините телефоны кабелем и разблокируйте iPhone.
3. Нажмите **«Подключить»**. Разрешите USB-доступ на Android и подтвердите доверие на iPhone, если появится запрос.
4. Через **«Выбрать IPA»** укажите файл и нажмите **«Установить»**. Не отключайте кабель до сообщения **«Приложение установлено»**.

Если при запуске приложения потребуется Apple ID, используйте учётную запись, с которой скачан IPA.

## Решение проблем

- **iPhone не определяется:** проверьте OTG и кабель. При проблемах с USB-C ↔ USB-C подключите OTG-переходник или хаб к Android, а iPhone — к нему. [Помощь с подключением](docs/TESTING.md).
- **Ошибка установки:** IPA должен быть совместим с iOS и иметь действующую подпись. Программа не переподписывает файл и не снимает привязку к Apple ID.

Для обращения об ошибке нажмите **«Сохранить журнал»** и удалите из журнала личные данные.
