# IPA USB

Устанавливает готовые IPA-файлы на iPhone с Android через USB. Компьютер для установки не нужен. Предварительная установка программ на iPhone не требуется.

**[Скачать APK](https://github.com/TapOk38/ipa-desk-multi/releases/download/android-v0.6.0-beta.1/ipa-usb-0.6.0-beta.1.apk)** · Версия 0.6.0-beta.1

## Требования

Android 8.0+ с поддержкой OTG, USB-кабель с передачей данных и IPA-файл на Android. При необходимости используется OTG-переходник или USB-хаб.

Для скачивания IPA из App Store используйте [IPA Desk Multi на Windows](../docs/DOWNLOAD.md), затем перенесите файл на Android.

## Использование

1. Установите APK на Android и сохраните на нём нужный IPA. Разрешите установку из выбранного источника, если Android запросит.
2. Включите OTG, если такой переключатель есть в настройках. Соедините телефоны кабелем и разблокируйте iPhone.
3. В IPA USB нажмите **«Подключить»**. Разрешите USB-доступ на Android и подтвердите доверие на iPhone, если появится запрос.
4. Через **«Выбрать IPA»** укажите файл и нажмите **«Установить»**. Не отключайте кабель до сообщения **«Приложение установлено»**.

Откройте приложение на iPhone. Если потребуется Apple ID и пароль, введите данные учётной записи, с которой скачан IPA.

## Решение проблем

- **iPhone не определяется:** проверьте OTG и кабель. Если USB-C ↔ USB-C не работает, подключите OTG-переходник или хаб к Android, а iPhone — к нему. [Помощь с подключением](docs/TESTING.md).
- **Ошибка установки:** IPA должен быть совместим с iOS и иметь действующую подпись. Программа не переподписывает приложения и не снимает привязку к Apple ID.

При обращении об ошибке приложите журнал, доступный по кнопке **«Сохранить журнал»**, предварительно удалив личные данные.
