# IPA Desk Multi

[Русский](DOWNLOAD.md) | **English**

Downloads apps from the App Store on Windows. Saves a separate IPA for each selected account.

**[Download EXE](https://github.com/TapOk38/ipa-desk-multi/releases/download/suite-v1.0.0-beta.1/IPA-Desk-Multi-0.4.0-beta.1.exe)** · 0.4.0-beta.1

## Requirements

Windows 10/11 x64, an internet connection and an Apple ID configured for the App Store. If two-factor authentication is enabled, access to the verification code is required.

## Usage

1. Run the EXE. Select the interface language if needed.
2. Click **Add** and enter the Apple ID, password and account description.
3. Paste an App Store link or app ID. Select the accounts and click **Download IPA**.
4. Enter a verification code if Apple requests it. When the download finishes, click **Open folder**.

Accounts are processed sequentially. Files are saved to **Downloads → IPA Desk Multi**. Each filename includes the app, version, Apple ID and account description.

Required components are downloaded automatically on first use.

## Installation and limitations

Use [IPA Install](../installer/README.en.md) or [IPA USB](../android/README.en.md) to install the file. Launching the app may require the Apple ID used to download it.

The app must be available to the selected account. A license for a free app is acquired automatically; paid purchases are not made.

Bulk downloading while switching between many Apple IDs on one PC is not recommended; no verified safe limit is known.

If an error occurs, check the log and include it in an issue after removing personal information.
