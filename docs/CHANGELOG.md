# Changelog

## suite-v1.0.0-beta.2 — 2026-10-12

- English is the default interface language in all three apps; saved preferences are preserved.
- Fixed Android window compatibility settings for tall screens and system-bar insets.
- Fixed the clipped Android language selector.
- Organized source code into separate application folders.
- Consolidated technical documentation in English; app descriptions remain bilingual.

## suite-v1.0.0-beta.1 — 2026-10-12

- Combined release of IPA Desk Multi 0.4.0-beta.1, IPA Install 1.1.0-beta.1 and IPA USB 0.7.0-beta.1.
- Russian and English interfaces with a saved language preference.
- Added bilingual descriptions and guides.

## 0.3.0-beta.2 — 2026-10-12

- Shortened the description, startup guide and reference documents.
- Updated documentation inside the ZIP.
- Fixed ZIP checks in a clean Windows PowerShell environment.

## 0.3.0-beta.1 — 2026-10-12

- First public release.
- Sequential downloads for selected Apple IDs.
- Account descriptions and separate IPA filenames containing app metadata.
- Support for Unicode paths and automatic ipatool-cpp preparation.
