# IPA Desk Multi — скачивание IPA

Скачивает приложение из App Store на компьютер Windows. Укажите ссылку или ID приложения и выберите учётки: программа обработает их по очереди и сохранит **отдельный IPA для каждой**.

**[Скачать IPA Desk Multi.exe](https://github.com/TapOk38/ipa-desk-multi/releases/download/v0.3.1-beta.1/IPA-Desk-Multi-0.3.1-beta.1.exe)**

## Что нужно

Windows 10/11 x64, интернет и Apple ID. Подключать iPhone или заранее устанавливать на него приложение не нужно. EXE запускается без установки; при первом скачивании необходимые компоненты загружаются автоматически.

## Как скачать

1. Запустите программу. Нажмите **«Добавить»**, введите Apple ID, пароль и удобное описание учётки.
2. В поле **«Ссылка или ID»** вставьте ссылку App Store или числовой ID приложения.
3. Отметьте нужные учётки и нажмите **«Скачать IPA»**. Если Apple запросит код подтверждения, введите его.
4. Дождитесь **«IPA сохранён»** и нажмите **«Открыть папку»**.

Файлы сохраняются в **Загрузки → IPA Desk Multi**, по папкам приложения и учёток. Имя IPA содержит название и версию приложения, Apple ID и описание учётки. Учётки сохраняются между запусками, их можно редактировать и удалять.

## После скачивания

Установите файл через [IPA Install на Windows](../installer/README.md) или перенесите его на Android и используйте [IPA USB](../android/README.md).

Приложение должно быть доступно выбранной учётке. Для бесплатного приложения программа при необходимости получает лицензию; платные покупки не выполняются. При запуске на iPhone может понадобиться Apple ID, с которым скачан IPA.

Не рекомендуем массовое скачивание со сменой множества Apple ID на одном ПК: подтверждённого безопасного лимита нет.

Если скачивание не удалось, посмотрите журнал внизу окна. Для помощи [сообщите об ошибке](https://github.com/TapOk38/ipa-desk-multi/issues), убрав личные данные.
