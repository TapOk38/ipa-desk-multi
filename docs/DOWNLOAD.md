# IPA Desk Multi

Скачивает приложения из App Store на Windows. Для каждой выбранной учётной записи сохраняется отдельный IPA-файл.

**[Скачать EXE](https://github.com/TapOk38/ipa-desk-multi/releases/download/v0.3.1-beta.1/IPA-Desk-Multi-0.3.1-beta.1.exe)** · Версия 0.3.1-beta.1

## Требования

Windows 10/11 x64, интернет и Apple ID с настроенным App Store. При включённой двухфакторной аутентификации необходим доступ к коду подтверждения.

Программа запускается без установки. Необходимые компоненты загружаются автоматически при первом использовании. Подключать iPhone и заранее устанавливать на него приложение не требуется.

## Использование

1. Запустите EXE. Нажмите **«Добавить»**, укажите Apple ID, пароль и описание учётной записи.
2. Вставьте ссылку App Store или числовой ID в поле **«Ссылка или ID»**.
3. Отметьте учётные записи и нажмите **«Скачать IPA»**. Введите код подтверждения, если Apple его запросит.
4. После сообщения **«IPA сохранён»** нажмите **«Открыть папку»**.

Учётные записи обрабатываются последовательно и сохраняются между запусками. Их можно редактировать и удалять.

Файлы находятся в **Загрузки → IPA Desk Multi**. Имя IPA содержит название и версию приложения, Apple ID и описание учётной записи.

## Установка на iPhone

Используйте [IPA Install на Windows](../installer/README.md) или перенесите файл на Android для установки через [IPA USB](../android/README.md). При запуске приложения может потребоваться Apple ID, с которым скачан IPA.

Приложение должно быть доступно выбранной учётной записи. Лицензия на бесплатное приложение при необходимости получается автоматически. Платные покупки не выполняются.

Массовое скачивание со сменой множества Apple ID на одном ПК не рекомендуется: подтверждённого безопасного лимита нет.

При ошибке проверьте журнал внизу окна. При сообщении об ошибке приложите её текст без личных данных.
