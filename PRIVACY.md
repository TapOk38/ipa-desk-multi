# Хранение данных

**Русский** | [English](PRIVACY.en.md)

## Учётные записи

Apple ID, описание и пароль сохраняются в `%LOCALAPPDATA%\IPA-Desk-Multi\accounts.json`.
Пароль зашифрован средствами Windows DPAPI и доступен текущему пользователю Windows.
Apple ID и описание хранятся открытым текстом.

Коды 2FA программа не сохраняет. Для каждой операции создаётся отдельный временный профиль,
который удаляется после её завершения. При аварийном закрытии временные файлы могут остаться.
Сохранённая учётная запись не гарантирует вход без повторного кода подтверждения.

Выбранный язык сохраняется отдельно в файле `language.txt` в той же папке данных приложения.

## Сетевые обращения

При первой подготовке компонент ipatool-cpp скачивается с GitHub. Авторизацию, получение
лицензии и скачивание приложения он выполняет через серверы Apple. Apple ID не отправляется
GitHub. Телеметрии в оболочке нет.

## IPA и журналы

Имя IPA и сам файл могут содержать данные Apple ID. Удаление учётной записи из списка не удаляет
скачанные IPA. Журнал и скриншоты могут содержать адрес почты, описание учётной записи и пути к файлам —
скрывайте их перед отправкой.

Пароль и код 2FA передаются ipatool-cpp через аргументы процесса. Их может прочитать локальное
ПО с достаточными правами, поэтому используйте доверенный компьютер. Не публикуйте файл
`accounts.json`, пароли, коды подтверждения и файлы сессий.

## Версия с EXE

Компоненты распаковываются в `%LOCALAPPDATA%\IPA-Desk-Multi\app`. Скачанные IPA сохраняются в системной папке «Загрузки → IPA Desk Multi». Учётные записи хранятся отдельно и сохраняются при обновлении EXE.
