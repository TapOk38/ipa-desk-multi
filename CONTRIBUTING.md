# Разработчикам

**Русский** | [English](CONTRIBUTING.en.md)

В репозитории три отдельные программы:

| Программа | Исходники | Сборка и проверки |
| --- | --- | --- |
| IPA Desk Multi | Корень репозитория | [Windows: скачивание](docs/BUILDING.md) |
| IPA Install | `installer/` | [Windows: установка](installer/BUILDING.md) |
| IPA USB | `android/` | [Android: установка](android/docs/BUILDING.md) |

Код Windows-программ — [MIT](LICENSE), Android — [GPL-3.0-only](android/LICENSE). Лицензии сторонних компонентов находятся рядом с каждым приложением.

Для изменений опишите ожидаемый результат и запустите проверки соответствующей программы. Используйте вымышленные учётки и тестовые IPA; не добавляйте реальные приложения, пароли, ключи подписи и личные журналы.

Для новой зависимости укажите версию, источник и лицензию. Не отключайте проверки TLS и контрольных сумм. В PR кратко опишите изменение и выполненные проверки.
